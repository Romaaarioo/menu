# Our Home

Общее домашнее меню для двоих с идеями блюд для завтрака, обеда, ужина и сладкого. В приложении есть рецепты русской кухни, случайный выбор, поиск, избранное, план недели, список покупок, оценки, отметки недавно приготовленных блюд и фильтр продуктов дома. Работает как статический сайт без сборки и сервера.

## Запуск

Откройте `index.html` в браузере или опубликуйте папку через GitHub Pages.

## Публикация на GitHub Pages

1. Создайте отдельный репозиторий GitHub и загрузите в него файлы **из этой папки**.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. После публикации приложение будет доступно по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

В нижней панели «Все» показывает полный список, а остальные пункты открывают отдельные разделы. Рандомайзер работает в пределах открытого раздела. Новые блюда можно добавить кнопкой над списком; готовые рецепты редактируются и удаляются из карточки рецепта. В диалоге блюда его можно оценить, отметить приготовленным или добавить в план. План недели позволяет выбрать дату, приём пищи и блюдо; список покупок собирает ингредиенты запланированных блюд. Рецепты, избранное, план, список покупок, оценки и продукты дома сохраняются только в текущем браузере — для синхронизации между устройствами потребуется облачное хранилище.

## Идеи для следующих версий

- Конструктор собственных рецептов и импорт по ссылке.
- План меню на неделю с перетаскиванием блюд по дням.
- Список покупок, который собирается из выбранных рецептов.
- Фильтры по времени, бюджету, диете и продуктам «уже есть дома».
- Режим готовки с пошаговыми инструкциями и таймерами.
- Установка на телефон как PWA и синхронизация между устройствами.
